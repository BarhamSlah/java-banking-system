# 🏦 Java Banking System

A secure, console-based banking application written in Java. Manage your accounts, perform deposits, check balances, and handle basic banking operations with robust input handling.

---

## 📌 Features

- **Account Management:** Create and track user account information.
- **Core Transactions:** Perform deposits, withdrawals, and balance checks seamlessly.
- **Input Validation:** Ensures secure, error-free numeric entries and prevents invalid transactions (such as negative withdrawals or overdrafts).
- **Interactive CLI Loop:** Continuous user menu to perform multiple transactions in a single session.

---

## 🛠️ Built With

- **Language:** Java (JDK 17 or higher recommended)
- **Core APIs:** `java.util.Scanner`
- **IDE:** IntelliJ IDEA
- **Version Control:** Git & GitHub
