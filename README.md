# Java Banking System

A simple console-based banking application built with Java as a learning project.

## 📌 Features

- Create and manage accounts
- Deposit money
- Withdraw money
- Check balances
- Basic input validation
- Interactive console menu

## 🧠 Concepts Practiced

- Classes and Objects
- Encapsulation
- Methods
- Conditions and loops
- User input with Scanner
- Basic validation

## 🛠️ Built With

- Java
- IntelliJ IDEA
- Git & GitHub

## 🎯 Purpose

This project was created to practice Java fundamentals by building a small working application.

> This is a learning project, not a production banking system.
